# PS57 – Mental Wellness Journal Companion

A journaling app that gives supportive replies, detects mood, saves entries
locally and shows helpline numbers (Tele-MANAS 14416, emergency 112) when an
entry suggests distress. Not medical advice.

## Tech
Python, Streamlit, Groq API (GPT-OSS 20B), pandas

## How to run
1. pip install -r requirements.txt
2. Create a .env file with: GROQ_API_KEY=your_key
3. streamlit run app.py
